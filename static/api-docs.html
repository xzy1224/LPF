LPF API 文档

基础说明：
  • 开放API使用URL参数传递Token：?token=YOUR_TOKEN
  • 所有API返回JSON格式数据
  • Base URL: http://localhost:8188
认证接口 文件管理接口 Token管理接口 文件收取接口 开放API接口

一、认证接口

POST /api/auth/login - 用户登录

请求头：

Content-Type application/json

请求体：

{
  "username": "admin",
  "password": "admin123"
}

响应：

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "admin",
    "role": "admin"
  }
}

错误响应：

{ "error": "Invalid username or password" }
POST /api/auth/register - 用户注册

请求体：

{
  "username": "user",
  "password": "123456"
}

响应：

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 2,
    "username": "user"
  }
}
GET /api/auth/me - 获取当前用户信息

请求头：

Authorization: Bearer YOUR_TOKEN

响应：

{
  "id": 1,
  "username": "admin",
  "role": "admin",
  "created_at": "2024-01-01 00:00:00"
}
PUT /api/auth/password - 修改密码

请求头：

Authorization: Bearer YOUR_TOKEN
Content-Type: application/json

请求体：

{
  "oldPassword": "old_password",
  "newPassword": "new_password"
}

响应：

{ "message": "Password updated successfully" }

二、文件管理接口

GET /api/files - 文件列表

请求头：

Authorization: Bearer YOUR_TOKEN

查询参数：

search文件名搜索关键字（可选）
sort排序字段：created_at, name, size（可选，默认created_at）
order排序方式：asc, desc（可选，默认desc）
page页码（可选，默认1）
pageSize每页数量（可选，默认20）
dateFilter日期筛选：today, week, month, all（可选）

响应：

{
  "list": [
    {
      "id": 1,
      "filename": "xxx.pdf",
      "original_name": "test.pdf",
      "size": 1024,
      "created_at": "2024-01-01 00:00:00",
      "is_preview_open": 1,
      "owner": "admin"
    }
  ],
  "total": 100,
  "page": 1,
  "pageSize": 20,
  "totalPages": 5
}
POST /api/files/upload - 文件上传

请求头：

Authorization: Bearer YOUR_TOKEN

表单字段：

file上传的文件（必填）

响应：

{
  "id": 1,
  "filename": "xxx.pdf",
  "original_name": "test.pdf",
  "size": 1024,
  "message": "File uploaded successfully"
}
GET /api/files/:id - 获取文件信息

路径参数：

id文件ID（必填）

响应：

{
  "id": 1,
  "filename": "xxx.pdf",
  "original_name": "test.pdf",
  "size": 1024,
  "created_at": "2024-01-01 00:00:00",
  "is_preview_open": 1
}
GET /api/files/:id/preview - 预览文件信息

路径参数：

id文件ID（必填）

响应：

{
  "file": { ... },
  "fileType": { "type": "pdf", "mimeType": "application/pdf" },
  "previewUrl": "/uploads/xxx.pdf"
}
GET /api/files/:id/download - 下载文件

路径参数：

id文件ID（必填）

响应：返回文件二进制数据

DELETE /api/files/:id - 删除文件

路径参数：

id文件ID（必填）

响应：

{ "message": "File deleted successfully" }
PUT /api/files/:id/preview-open - 开启/关闭预览

路径参数：

id文件ID（必填）

请求体：

{ "open": true }

响应：

{ "message": "Preview updated successfully" }
POST /api/files/:id/share - 分享文件

路径参数：

id文件ID（必填）

请求体：

{
  "type": "permanent",  // permanent 或 temporary
  "expiresAt": "2024-12-31T23:59:59"  // 过期时间（temporary时必填）
}

响应：

{
  "id": 1,
  "file_id": 1,
  "token": "xxx",
  "type": "permanent",
  "expires_at": null,
  "download_url": "/api/share/download/xxx"
}
GET /api/files/shares/list - 分享列表

响应：

{
  "list": [
    {
      "id": 1,
      "file_id": 1,
      "token": "xxx",
      "type": "permanent",
      "created_at": "2024-01-01"
    }
  ]
}

三、Token管理接口

GET /api/tokens - Token列表

查询参数：

page页码（可选）
pageSize每页数量（可选）

响应：

{
  "list": [
    {
      "id": 1,
      "token": "xxx",
      "name": "My Token",
      "type": "permanent",
      "disabled": 0,
      "expires_at": null,
      "created_at": "2024-01-01"
    }
  ],
  "total": 10,
  "page": 1,
  "pageSize": 20
}
POST /api/tokens - 创建Token

请求体：

{
  "name": "My API Token",
  "type": "permanent",  // permanent 或 temporary
  "expiresAt": "2024-12-31T23:59:59"  // 过期时间（可选）
}

响应：

{
  "id": 1,
  "token": "0dce8970-1482-4e53-ad8c-e4d28a5db52b",
  "name": "My API Token",
  "type": "permanent",
  "message": "Token created successfully"
}
PUT /api/tokens/:id - 更新Token

路径参数：

idToken ID（必填）

请求体：

{
  "name": "New Name",
  "disabled": false
}
DELETE /api/tokens/:id - 删除Token

路径参数：

idToken ID（必填）

响应：

{ "message": "Token deleted successfully" }

五、开放API接口

认证方式：所有开放API通过URL参数传递Token：?token=YOUR_TOKEN
GET /api/public/files - 文件列表查询

URL参数：

tokenAPI Token（必填）
page页码（可选，默认1）
pageSize每页数量（可选，默认20）

示例：

GET /api/public/files?token=YOUR_TOKEN&page=1&pageSize=10

响应：

{
  "list": [
    {
      "id": 1,
      "filename": "xxx.pdf",
      "original_name": "test.pdf",
      "size": 1024,
      "created_at": "2024-01-01",
      "is_preview_open": 1
    }
  ],
  "total": 100,
  "page": 1,
  "pageSize": 20,
  "totalPages": 5
}
POST /api/public/upload - 文件上传

URL参数：

tokenAPI Token（必填）

表单字段：

file上传的文件（必填）

示例：

POST /api/public/upload?token=YOUR_TOKEN

响应：

{
  "id": 1,
  "filename": "xxx.pdf",
  "original_name": "test.pdf",
  "size": 1024,
  "message": "File uploaded successfully"
}
DELETE /api/public/files/:id - 文件删除

URL参数：

tokenAPI Token（必填）

路径参数：

id文件ID（必填）

示例：

DELETE /api/public/files/1?token=YOUR_TOKEN

响应：

{ "message": "File deleted successfully" }
GET /api/public/preview/:id - 文件预览

URL参数：

tokenAPI Token（必填）

路径参数：

id文件ID（必填）

示例：

GET /api/public/preview/1?token=YOUR_TOKEN

说明：返回文件内容，可在浏览器中直接预览。需在文件管理中开启"开放预览"开关。

GET /api/public/download/:id - 文件下载

URL参数：

tokenAPI Token（必填）

路径参数：

id文件ID（必填）

示例：

GET /api/public/download/1?token=YOUR_TOKEN

响应：返回文件二进制数据

POST /api/public/upload/chunk - 分片上传

URL参数：

tokenAPI Token（必填）

表单字段：

filename文件名（必填）
chunk当前分片编号，从0开始（必填）
chunks总分片数（必填）
chunkData分片文件数据（必填）

示例：

POST /api/public/upload/chunk?token=YOUR_TOKEN

响应（未完成）：

{
  "chunk": 0,
  "uploaded": 1,
  "total": 5,
  "message": "Chunk uploaded successfully"
}

响应（完成）：

{
  "id": 1,
  "filename": "xxx.pdf",
  "size": 1024,
  "message": "File uploaded successfully"
}
POST /api/public/upload/chunk/check - 分片上传检查

URL参数：

tokenAPI Token（必填）

请求体：

{
  "filename": "test.pdf",
  "chunk": 0,
  "chunks": 5
}

响应：

{
  "uploadedChunks": [0, 1, 2],
  "needUpload": true
}
