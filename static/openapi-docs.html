一、文件上传

POST /api/public/upload - 单文件上传

请求头：

Content-Type multipart/form-data

URL参数：

token API Token（必填）

表单字段：

file 要上传的文件（必填）

请求示例：

POST /api/public/upload?token=YOUR_TOKEN

Content-Type: multipart/form-data
file: (二进制文件数据)

成功响应：

{
  "id": 1,
  "filename": "xxx.pdf",
  "original_name": "test.pdf",
  "size": 1024,
  "message": "File uploaded successfully"
}

二、批量上传

POST /api/public/upload/multiple - 批量上传文件

请求头：

Content-Type multipart/form-data

URL参数：

token API Token（必填）

表单字段：

files 文件数组（最多50个，必填）

请求示例：

POST /api/public/upload/multiple?token=YOUR_TOKEN

Content-Type: multipart/form-data
files: file1.txt
files: file2.txt
files: file3.txt

成功响应：

{
  "total": 3,
  "files": [
    { "id": 1, "filename": "xxx1.txt", "original_name": "file1.txt", "size": 100 },
    { "id": 2, "filename": "xxx2.txt", "original_name": "file2.txt", "size": 200 },
    { "id": 3, "filename": "xxx3.txt", "original_name": "file3.txt", "size": 300 }
  ],
  "message": "3 files uploaded successfully"
}

三、分片上传（断点续传）

适用场景：大文件上传（如视频、大型压缩包），支持断点续传
第一步 准备分片上传

将大文件分割成多个小分片（建议每个分片1MB-5MB），并计算总分片数。

例如：上传一个100MB的视频文件，每个分片1MB，则总分片数为100。

第二步 循环上传分片

使用 POST /api/public/upload/chunk 接口逐个上传分片：

接口地址 POST /api/public/upload/chunk?token=YOUR_TOKEN
Content-Type multipart/form-data
filename 最终文件名（如 video.mp4）
chunk 当前分片编号，从0开始（0, 1, 2, ...）
chunks 总分片数（如 100）
chunkData 当前分片的二进制数据

调用示例：

POST /api/public/upload/chunk?token=YOUR_TOKEN

--boundary
Content-Disposition: form-data; name="filename"

video.mp4
--boundary
Content-Disposition: form-data; name="chunk"

0
--boundary
Content-Disposition: form-data; name="chunks"

100
--boundary
Content-Disposition: form-data; name="chunkData"; filename="chunk0"

(二进制数据)
--boundary--
第三步 检查上传结果

每次上传一个分片后，检查响应内容：

响应类型 响应内容 后续操作
上传中 
{
  "chunk": 0,
  "uploaded": 1,
  "total": 100,
  "message": "Chunk uploaded successfully"
}
 继续上传下一个分片（chunk+1）
上传完成 
{
  "id": 1,
  "filename": "video.mp4",
  "size": 104857600,
  "message": "File uploaded successfully"
}
 所有分片已上传完成！
完整调用流程

流程说明：

  1. 计算文件大小和分片数量，确定每个分片的大小
  2. 设置 filename = "video.mp4"，chunks = 100
  3. 循环从 chunk = 0 开始上传：
    • 读取第 chunk 个分片的数据作为 chunkData
    • 发送 POST 请求到 /api/public/upload/chunk?token=YOUR_TOKEN
    • 检查响应：如果响应中包含 id 字段，说明上传完成，停止循环
    • 如果响应中没有 id 字段，chunk++，继续上传下一个分片
  4. 当响应中包含 id 时，分片上传全部完成
简化逻辑：只需要循环上传分片，当响应中出现了 "id": 数字 时，就表示所有分片已经上传完成，可以停止上传了。
POST /api/public/upload/chunk - 分片上传

请求头：

Content-Type multipart/form-data

URL参数：

token API Token（必填）

表单字段：

filename 最终文件名（如 video.mp4，必填）
chunk 当前分片编号，从0开始（如 0, 1, 2...，必填）
chunks 总分片数（如 100，必填）
chunkData 当前分片的二进制数据（必填）

上传中响应：

{
  "chunk": 0,
  "uploaded": 1,
  "total": 100,
  "message": "Chunk uploaded successfully"
}

上传完成响应：

{
  "id": 1,
  "filename": "video.mp4",
  "size": 104857600,
  "message": "File uploaded successfully"
}

四、分片上传检查（断点续传）

POST /api/public/upload/chunk/check - 检查已上传的分片

请求头：

Content-Type application/json

URL参数：

token API Token（必填）

请求体：

{
  "filename": "video.mp4",
  "chunk": 0,
  "chunks": 100
}

响应：

{
  "uploadedChunks": [0, 1, 2, 5, 8],
  "needUpload": true
}

响应说明：

  • uploadedChunks: 已上传的分片编号数组
  • needUpload: 当前分片是否需要上传（true=需要，false=已存在）

使用场景：上传中断后，使用此接口检查已上传的分片，只上传未完成的部分（断点续传）。

五、文件列表查询

GET /api/public/files - 获取文件列表

URL参数：

token API Token（必填）
page 页码（可选，默认1）
pageSize 每页数量（可选，默认20）

请求示例：

GET /api/public/files?token=YOUR_TOKEN&page=1&pageSize=10

响应：

{
  "list": [
    {
      "id": 1,
      "filename": "xxx.pdf",
      "original_name": "test.pdf",
      "size": 1024,
      "created_at": "2024-01-01",
      "is_preview_open": 1
    }
  ],
  "total": 100,
  "page": 1,
  "pageSize": 20,
  "totalPages": 5
}

六、文件预览

GET /api/public/preview/:id - 预览文件

URL参数：

token API Token（必填）
id 文件ID（路径参数，必填）

请求示例：

GET /api/public/preview/1?token=YOUR_TOKEN

说明：

  • 返回文件内容，可在浏览器中直接预览
  • 支持图片、PDF、视频、音频等格式
  • 需要在文件管理中开启"开放预览"开关

七、文件下载

GET /api/public/download/:id - 下载文件

URL参数：

token API Token（必填）
id 文件ID（路径参数，必填）

请求示例：

GET /api/public/download/1?token=YOUR_TOKEN

说明：返回文件下载（Content-Disposition: attachment）

八、文件删除

DELETE /api/public/files/:id - 删除文件

URL参数：

token API Token（必填）
id 文件ID（路径参数，必填）

请求示例：

DELETE /api/public/files/1?token=YOUR_TOKEN

成功响应：

{ "message": "File deleted successfully" }
注意事项：
  • 使用Token管理中创建的有效Token
  • 确保Token未过期且未禁用
  • 预览功能需要在文件管理中开启"开放预览"开关
