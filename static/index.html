三、分片上传（详细流程）
适用场景：大文件上传（如视频、大型压缩包），支持断点续传
分片上传完整流程（小白教程）
第一步：计算文件分片

假设要上传一个 100MB 的视频文件，每个分片 1MB，则需要分成 100 个分片。

第二步：逐个上传分片

使用以下接口循环上传每个分片：

POST /api/public/upload/chunk
URL参数 token - API Token
表单字段
  • filename - 最终文件名（如 video.mp4）
  • chunk - 当前分片编号（0, 1, 2, ..., 99）
  • chunks - 总分片数（100）
  • chunkData - 当前分片的二进制数据
第三步：上传示例（Python代码）
import requests
import os

BASE_URL = "http://你的IP:8188"
TOKEN = "你的TOKEN"

def upload_large_file(file_path, chunk_size=1024*1024):
    """分片上传大文件"""
    filename = os.path.basename(file_path)
    file_size = os.path.getsize(file_path)
    total_chunks = (file_size + chunk_size - 1) // chunk_size

    print(f"文件大小: {file_size} bytes, 分片数: {total_chunks}")

    with open(file_path, 'rb') as f:
        for chunk_index in range(total_chunks):
            chunk_data = f.read(chunk_size)

            # 上传当前分片
            files = {'chunkData': ('chunk', chunk_data)}
            data = {
                'filename': filename,
                'chunk': str(chunk_index),
                'chunks': str(total_chunks)
            }

            response = requests.post(
                f"{BASE_URL}/api/public/upload/chunk?token={TOKEN}",
                files=files,
                data=data
            )

            result = response.json()
            print(f"上传分片 {chunk_index+1}/{total_chunks}: {result.get('message', result)}")

            # 如果返回了id，说明上传完成
            if 'id' in result:
                print(f"上传完成! 文件ID: {result['id']}")
                return result['id']

    return None

# 使用示例
upload_large_file("D:/video.mp4")
第三步：上传示例（JavaScript/Node.js代码）
const axios = require('axios');
const fs = require('fs');
const path = require('path');

const BASE_URL = 'http://你的IP:8188';
const TOKEN = '你的TOKEN';

async function uploadLargeFile(filePath, chunkSize = 1024 * 1024) {
  const filename = path.basename(filePath);
  const fileSize = fs.statSync(filePath).size;
  const totalChunks = Math.ceil(fileSize / chunkSize);

  console.log(`文件大小: ${fileSize} bytes, 分片数: ${totalChunks}`);

  const fileBuffer = fs.readFileSync(filePath);

  for (let chunk = 0; chunk < totalChunks; chunk++) {
    const start = chunk * chunkSize;
    const end = Math.min(start + chunkSize, fileSize);
    const chunkData = fileBuffer.slice(start, end);

    const formData = new FormData();
    formData.append('filename', filename);
    formData.append('chunk', chunk.toString());
    formData.append('chunks', totalChunks.toString());
    formData.append('chunkData', new Blob([chunkData]), 'chunk');

    const response = await axios.post(
      `${BASE_URL}/api/public/upload/chunk?token=${TOKEN}`,
      formData
    );

    console.log(`上传分片 ${chunk + 1}/${totalChunks}: ${response.data.message || response.data}`);

    if (response.data.id) {
      console.log(`上传完成! 文件ID: ${response.data.id}`);
      return response.data.id;
    }
  }
}

// 使用示例
uploadLargeFile('D:/video.mp4');

四、分片上传检查（断点续传）
POST /api/public/upload/chunk/check
请求头 Content-Type: application/json
URL参数 token - API Token（必填）
请求体 
{
  "filename": "video.mp4",
  "chunk": 0,
  "chunks": 100
}
响应 
{
  "uploadedChunks": [0, 1, 2],
  "needUpload": true
}

uploadedChunks: 已上传的分片编号数组
needUpload: 当前分片是否需要上传
使用场景 上传中断后，使用此接口检查已上传的分片，只上传未完成的部分（断点续传）

六、文件预览
GET /api/public/preview/:id
URL参数
  • token - API Token（必填）
  • id - 文件ID（路径参数，必填）
请求示例 GET /api/public/preview/1?token=YOUR_TOKEN
说明 返回文件内容，可在浏览器中直接预览。支持图片、PDF、视频、音频等格式。
注意：需要在文件管理中开启"开放预览"开关。
七、文件下载
GET /api/public/download/:id
URL参数
  • token - API Token（必填）
  • id - 文件ID（路径参数，必填）
请求示例 GET /api/public/download/1?token=YOUR_TOKEN
说明 返回文件下载（Content-Disposition: attachment）
八、文件删除
DELETE /api/public/files/:id
URL参数
  • token - API Token（必填）
  • id - 文件ID（路径参数，必填）
请求示例 DELETE /api/public/files/1?token=YOUR_TOKEN
响应 
{ "message": "File deleted successfully" }
注意事项：
  • 使用Token管理中创建的有效Token
  • 确保Token未过期且未禁用
  • 预览功能需要在文件管理中开启"开放预览"开关
